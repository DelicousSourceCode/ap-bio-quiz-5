# Greek Affixes Matching Quiz

A standalone, offline-friendly matching quiz for Greek affixes from micro- through pent-.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `greek-affixes-quiz`).
2. Upload `index.html` to the repository's top level (the root).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. After GitHub finishes publishing, the site will be available at:
   `https://YOUR-USERNAME.github.io/greek-affixes-quiz/`

The quiz is a static HTML file and does not require a build step or external dependencies.
